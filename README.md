# Домашнее задание «Работа с ORM, 2 часть»

Репозиторий содержит два учебных Django-проекта по работе с объектно-реляционным отображением (ORM):

- [`orm_migrations`](orm_migrations/) — замена связи «один ко многим» на «многие ко многим» в модели «Школа».
- [`m2m-relations`](m2m-relations/) — реализация тематических тегов для статей через промежуточную модель с поддержкой основного тега.

Каждый проект имеет собственный `README.md` с инструкцией по установке и запуску.

> 💡 Работа выполнена в соответствии с требованиями задания:  
> - использование PostgreSQL,  
> - валидация одного основного тега в админке,  
> - корректная сортировка тегов на главной странице,  
> - оптимизация запросов через `prefetch_related` и `Prefetch`.
